# Neck voicings: decision log

The voicings engine (`web/lib/voicings/`) and the neck (`web/app/neck*.tsx`) as each story
left them, oldest rules first. Every entry is dated or cited by issue, and records the rule, the
measurement behind it and its known limits. A later entry can narrow or overturn an earlier one,
and says so ("since #1849 …"). **The code is the authority**: each paragraph names the
function or table that holds its rule, so grep that symbol before trusting a number here.

The live contract a cold reader needs is the Voicings row of [`web/CLAUDE.md`](../../web/CLAUDE.md).
Moved here verbatim from that row (#1866, 2026-10-22); the headings are new.

**Adding an entry.** A voicing story appends its paragraph under a new heading at the end, in the
shape the others use: the rule and its symbols, the grips and fingerings it moves (with frets),
the sweep it was measured on (moved lines by setup; nothing up the neck or on ukulele unless
intended; hand jumps of three frets or more, read round the form), the judged tally of distinct
moved lines, and its known limits. The ship bar the recent stories held: jumps do not rise, and
at most 5% of at least 60 judged distinct moved lines (or of all of them, if fewer) read worse.

## The library boundary and the shell characterization (#1585, #1591)

Pure library, no UI or state. `NECK_INSTRUMENTS` (`voice-chart.ts`) is the one pref-id → instrument table; `lib/session.ts` validates a stored id against its keys (and a home window against that instrument's `maxFret`) before anything indexes it. Chords come in only through `voicingChord` (the band's `ChordFacts`, spelled by `spellPitchClass`) — never a second parser or root table. The shell characterization (`lib/voicings/test/shell-characterization.test.ts` against `test/golden.json`, #1591) pins the shells' output note for note — shape, root fret, and each note's string, fret, degree, role AND finger — for 370 charts: guitar (any root string, and `classic`) and high-G uke × no window, 2–7 and 7–12 × ten progressions × C, F♯ and B♭, which reach six shell qualities (maj7, 7, m7, m7♭5, °7 and 6; the 7sus4 and m6 of #1817 are pinned in `engine.test.ts` instead), plus two low-G uke charts (low G voices as high G does — the voicer reads strings an octave apart as the same), one chart (`walk` in F) for what replaced the only shell grip that was wider than three frets (#1604, #1607), and the same three setups × ten progressions × three keys at frets 1–6, the window the app opens on (#1607: the only place the first-position rules act), and six `classic` guitar charts at frets 1–6 and 2–7 whose window holds no grip a player would take (#1610), and one ukulele chart (`canon` in A, frets 1–6) for the book grip a split symbol is held to (#1613). The fixture is this engine's own frozen output (it began as the prototype's, which is not in the repo), so a red case means a shell voicing CHANGED, not that it is wrong: an intended change regenerates it in the same commit — `UPDATE_VOICING_GOLDEN=1 npm run test:vitest -- shell-characterization` — and the fixture's diff is the review surface. The charts are listed in the test (`CASES`, over `test/keys.ts`'s progressions), chosen by mutation testing: adding one is free (after the others, so the fixture's diff is additions only), dropping one needs the measurement its comment describes.

## 7sus4 and m6 shells (#1817)

Eight shell qualities since #1817 (2026-10-20): the 7sus4 and the m6 join them in `QUALITIES`, R–4–♭7 (the 4th in the 3rd's seat, as a sus triad holds it) and R–♭3–6 (the 6th in the 7th's, as `six` holds it). The adapter used to reduce them to 7 and m7 with a notice (Wonderwall's A7sus4 showed A7's C♯ for the song's D); now 7sus4, 9sus4, 13sus4 and 11 read as 7sus4 (the shell drops their 9ths and 13ths, as a dom9's) and m6 and m6/9 as m6, with no notice.

## Guitar 7sus4 and m6 shells (#1817)

Guitar (up the neck; at the nut A7sus4, E7sus4, D7sus4 and Dm6 are the book's open chords since #1838): three-note shells on the existing shapes, A7sus4 `5 5 5 x x x` 1-2-3 (A7 `5 4 5 x x x` with its 3rd up a fret), G7sus4 `3 x 3 5 x x` 1-2-3, Am6 `5 x 4 5 x x` 2-1-3, `classic` Gm6 `3 x 2 3 x x` 2-1-3. The 5th-string m6's R–♭3–6 buries its root, so in `classic` frets 1–6 E♭m6 leaves `x 6 4 5 x x` for `x 6 x 5 7 x` a fret out, as m7♭5 and °7 do (#1610). A guitar 7sus4's R–3–7 shape on an open root frets nothing (A7sus4 `x 0 0 0 x x`, E7sus4 `0 0 0 x x x`, the only shells three neighbouring open strings hold) and is a last resort (`openStrum`, in `candidates`): offered, it took a Wonderwall in frets 1–6 onto the open strings (Em7 `0 x 0 0 x x`, G `x 2 0 0 x x`, Dsus4 `x 0 0 0 x x`), and without it the chart is main's with A7sus4 `x 0 x 0 3 x` where A7 was `x 0 x 0 2 x`. The R–7–3 open shells (Em7 `0 x 0 0 x x`) skip a string with no finger beside it to mute it, so they are gone: at the nut the 7th chords play the book's open chords since #1838, and up the neck they are a last resort since #1850, below; the fretless triads are a last resort too since #1822, below.

## A 7sus4 and its own 7 keep the root and ♭7 fingers (#1825)

A 7sus4 and its own 7 keep the root and ♭7 fingers down (#1825, 2026-10-20; up the neck since #1838, where at the nut `A7sus4 A7` is the book's `x 0 2 0 3 0` / `x 0 2 0 2 0`, 2-3 each, the ring finger sliding a fret): `A7sus4 A7` is `5 5 5` 2-3-4 into `5 4 5` 2-1-4, the ring finger lifting off the 4th and the index taking the 3rd a fret below ("Fingers 2 and 4 stay down; finger 1 goes down on the 5th string, fret 4."), and the same on every R–3–♭7 shape (D7sus4 D7, G7sus4 G7, `A7 A7sus4 A7` 2-1-4 throughout); it was 1-2-3 into 2-1-3, the root changing finger. A7 2-1-4 is 3.2 dearer than its cheapest, a crowded hand, so it is a second fingering (`suspensionOptions`, `FingerOption.resolves`): offered to a guitar shell, taken only beside its own suspension (`suspends`: every fretted note shared but one each, the 3rd and the 4th on one string), two fingers staying, priced at the margin. Unlike #1683's `crowdedOptions` the neighbour may be in any fingering it takes freely, not only its default (`besideIt`): the 7sus4's default 1-2-3 cannot keep the root where the 7 needs it, and its 2-3-4 is a taught fingering a held note may choose; two fingerings that each wait on the other still justify nothing (offered, `Bdim Bsus4 B7sus4 B7 F` in frets 5–10 went 1-3-4 / 1-3-4 to keep a note into F). The R–♭7–3 shapes already kept both (G7sus4 `3 x 3 5` to G7 `3 x 3 4`, 1-2-3 each) and are unchanged. Not wider, measured: offered for any note a fret along its string it took A7 `x x 7 6 8 x` to 3-2-4 into Am7 (the root on the ring finger: a crowded fingering skips `taughtAmong`'s root-first rule), A7 into Amaj7 to 1-3-4, the middle finger idle, and F♯6 `2 x 1 3` into F♯7 to 2-1-4 / 2-3-4, both crowded and no teacher asked; and on another string E7 `x x 2 x 3 4` took 1-3-4 into E7sus4 `x x 2 2 3 x`; triads are not asked, so the holds #1617 and #1683 ruled out (B♭ `x 5 3 3 x x` 4-2-3 after Dm, D `x x 4 2 3 x` 4-1-3 into Dm) stay out. Over 2,982 progressions × 15 setups no chart moved and the shell characterization is unchanged; over 3,120 with 7sus4 and m6, 85 charts moved (286 sweep lines, all guitar, fingers only), each a 7sus4 beside its own 7 or a neighbour taking a taught fingering that keeps the root for it (Am7 `5 x 5 5` 2-3-4 before A7sus4, Esus4 `x x 2 2 0 x` 2-3 before E7sus4 `x x 2 2 3 x`), and the 7sus4–7 changes that re-finger a shared note fell from 52–68 per guitar setup to 1 or 2. Known limits: `Csus4 C7sus4 C7` at the nut still re-fingers C once, between C7sus4 and C7, since Csus4 `x 3 3 0 x x` cannot keep the root under the middle finger for both; and C7sus4 alone in frets 2–7 is `x 3 x 3 6 x` 1-2-4 over `x 3 3 3 x x`: the window-centre pull, as for C6 `x 3 x 2 5 x`, not a rule of these chords. Over 2,982 progressions × 15 setups no chart without a 7sus4 or m6 moved, and the shell characterization is unchanged (no golden chart writes either chord).

## The open-string credit only for an open form's grip (#1833)

On a guitar, a triad or power grip earns the open-string credit only as part of its chord's open form (#1833, 2026-10-20, `openFormGrip` in `openStringCredit`, over `GUITAR_OPEN_CHORDS` in `instruments.ts`; since #1849 the chords with an open form play it whole at the nut, so the credit judges the three-string grips of the rest): every note on the string and fret it has in one of the open chords a beginner's book prints for that root and quality — C, A, G, E, D, Am, Em, Dm, Asus2, Asus4, Dsus2, Dsus4, Esus4, Csus4 `x 3 3 0 1 1`, Fsus2 `x x 3 0 1 1` and the open E5, A5 and D5. So E `x x 2 1 0 x` and A `x x x 2 2 0` keep it, and E♭ `x 1 1 0 x x`, B♭ in the bass and the open G for its 3rd, does not. Left out as a chord dictionary's grips rather than a lesson's: Gm `3 1 0 0 3 3`, Csus2 `x 3 0 0 1 3`, Gsus4 `3 3 0 0 1 3`. A diminished or augmented triad keeps the credit unjudged, measured: the table has no open forms for them, and judged, `E E° E` with no window went to `x x x 4 5 4` / `x x x 3 5 3` and #1827's chart closed its E7 and A♭dim again (`x x 2 x 3 4`, `x x x 4 3 4`). The ukulele is not asked. Alone in frets 1–6, E♭ is `x x x 3 4 3` (was `x 1 1 0 x x`) and Gm `x x x 3 3 3` (was `x 1 0 0 x x`); `E♭ E♭sus4 E♭` is `x x x 3 4 3` / `x x x 3 4 4`, `B♭ F Gm E♭` the tops of the 1st- and 3rd-fret barres (`x x x 3 3 1` / `x x x 2 1 1` / `x x x 3 3 3` / `x x x 3 4 3`), `F Fsus2 F` `x x 3 2 1 x` / `x x 3 0 1 x` (was `x 3 3 2 x x` / `x 3 3 0 x x`, Csus4's grip under another name) and `Gsus4 Gm Gsus4` `x x x 5 3 3` / `x x x 3 3 3`. Unchanged: `E Em E`, `Esus4 Em Esus4` (`x x 2 2 0 x`), Fsus2 alone `x x 3 0 1 x`, `C B° Am Em`'s Em `x 2 2 0 x x`, `C G Am F`, the open power chords, `E E° E`. Over 3,120 progressions × 15 setups 178 sweep lines moved (67 distinct progressions; 72 in guitar frets 1–6, 65 in `classic` 1–6, 41 with no window), none up the neck or on ukulele, and the shell characterization is unchanged. Of the grips that changed, 149 went into a CAGED open or barre form inside the 5th fret and 29 out of one (96 lines gained such a grip, 13 lost one), and hand jumps of three frets or more over the two nut setups fell from 404 to 388. The losses are neighbours re-set beside a chord that left its open string: D♭m off `x x x 1 2 0` took Dsus2 and Dm off the open D's top to `x x 2 2 3 x` / `x x 3 2 3 x` (`… Dsus2 Dm D♭m`), and Em `x 2 2 0 x x` went to `x x x 4 5 3` beside A♭m's 4th-fret barre. Known limits: taking the credit away is not taking the grip away. A grip is placed by its fretted notes (`handAt`), so an open string costs nothing there, and most of these grips sit as near the 2.5th fret without the credit: over the two nut setups Gsus4 `x 3 0 0 x x` is still in 85 of the 196 lines that hold a Gsus4 (was 102), Csus2 `x 3 0 0 x x` in 103 of 220 (119), Cm `x 3 1 0 x x` in 115 of 290 (117) and E♭ `x 1 1 0 x x` in 52 of 214 (78), and A♭m and D♭m took closed grips no book prints either (`x 2 1 1 x x`, `x 4 2 1 x x`, for `x x 1 1 0 x` and `x x x 1 2 0`). Holding such a grip back as a last resort at the nut, as `openStrum` holds the fretless ones, removes every one of them (and gives `G Gm G` the 3rd-fret barre's tops, `C Cm C` the A shape's), but moved 1,072 sweep lines and raised those hand jumps to 439, so it is left for a decision. Guitar shells aimed at first position as well (#1833's second option) were measured on top of this and left out: 265 sweep lines and 23 characterization charts moved, the shells mostly onto open and 1st-position 7ths (A7 `x 0 x 0 2 x`, D7 `x x 0 x 1 2`, B♭m7 `x 1 x 1 2 x`, C7 `x 3 2 3 x x`), but the triads beside them lost book grips (30 out, 6 in: Bsus2 `x x 4 4 2 x` to `x 4 4 4 x x`, Csus2 `x x 5 5 3 x` back to `x 3 0 0 x x`), hand jumps rose from 388 to 397, and `Gdim7 E7 A° A♭° Dsus4 Em Cm7`'s E7 stayed `x x 2 1 3 x` (taken since #1851, below, re-measured after the book chords).

## Ukulele add9 (#1820)

An add9 on a ukulele is its own quality since #1820 (2026-10-20), `add9`: the triad grip with the 9th in a seat the shape doubles (`QualityDef.added`, role `N`; `UKE_ADD9` in `instruments.ts`, five of the moving shapes, each with the one seat the charts use — the other seats gave grips no chart prints, Aadd9 `4 1 0 0` and Gadd9 `4 2 3 0`, which as open grips at the nut took the chord from the book's under `bookGrip`). In every other way it is a triad: strummed, costed by hand (`byHand`), one grip per symbol (`unifyGrips`), `bookGrip`/`firstPosition`, fingered by `taughtStrummed`. A shape with an `N` seat serves only a quality with an added tone, and that quality only such shapes (`taughtFor`). The adapter reads a major add9 (and an add2, which `parseChord` reads as the same chord) as `add9` only where the instrument has grips for it (`voicingChord`'s `instrument`, passed by `voiceBandChart`), so the guitar keeps the plain triad and its notice: its three-string triads have no string to spare, and its output is unchanged. The 9th is a degree of its own, `9` (labelled 9, spoken "9th", the 2nd's pitch class), so a sus2's 2 is still "the 2nd" and an add9's reads as the chord names it: G to Cadd9 is "D is in both chords: the 5th becomes the 9th; finger 2 takes it over …". Ukulele, frets 1–6 or no window, the charts' grips and fingerings (Kytary, and UkuTabs where read, 2026-10-20): Cadd9 `0 2 0 3` 0-2-0-3 (a `UKE_BOOK` row, with 0-1-0-3 second: Csus2 `0 2 3 3` 0-1-2-3 to Cadd9 lifts the middle finger, and `Cadd9 G` keeps the index on the C string's D; in `G Cadd9 D` that D changes finger once either way, G holding it with the index and D with the middle, so Cadd9 keeps 0-2-0-3), D♭add9 `1 3 1 4` and Dadd9 `2 4 2 5` 1-3-1-4, E♭add9 `0 3 1 1`, Eadd9 `1 4 2 2`, Fadd9 `0 0 1 0`, F♯add9 `1 1 2 1`, Gadd9 `2 2 3 2` and A♭add9 `3 3 4 3` 1-1-2-1, Aadd9 `2 1 0 2`, B♭add9 `3 2 1 3`, Badd9 `4 3 2 4`; the two barred forms are rows of `UKE_MOVING_BOOK` (what `UKE_F_SHAPE` became: keyed by the frets above the grip's lowest, so the barre holds at every fret). `C Cadd9 C` adds the middle finger under the ring finger's C, `F Fadd9` lifts F's middle finger, `G Cadd9 D` is `0 2 3 2` / `0 2 0 3` / `2 2 2 0`, and `G Gadd9 G` keeps G's three fingers and lays the index across the G and C strings (1-1-3-2). Up the neck the same shapes give the charts' other grips (Cadd9 `5 4 3 5` in frets 2–7, `7 7 8 7` in 5–10). Gadd9 at the nut is Kytary's `2 2 3 2` (UkuTabs's easier grip), not UkuTabs's first, `0 2 5 2`, which frets past the 4th fret and so loses the nut to `firstPosition` (in frets 2–7 it is the grip). `crowdedOptions`' suspension test reads the `2` and `4`, not the `9`: an add9 is no suspension, and only the guitar is asked there. Known limits: Eadd9 is 1-4-2-3, where the books lay the middle finger across the E and A strings, a barre the ukulele rules give only the index and ring finger (`barreOptions`); and a minor add9 keeps its reduction, since the same shapes put half its roots at the nut on grips no chart prints (Fm(add9) `1 5 3 3` for the book's `0 5 4 3`, Dm(add9) `2 4 1 5` for `7 5 5 7`). Over 2,982 progressions × 15 setups no chart without an add9 moved, and the shell characterization is unchanged.

## A shell keeps the tone that names it (#1606)

A shell keeps the tone that names it (#1606): a quality's `required` tones (`QUALITIES`: the ♭5 of m7♭5 and of °7) are enforced in ONE place, `allPositions`, which drops a grip that has no room for one (`Voicing.missing`, set by `buildAt`) whenever the chord has a complete grip, and keeps it only as a last resort so no chord goes unvoiced — complete before in-window, though in a six-fret window a complete grip always fits where any grip does. The guitar's °7 is therefore four notes (`x 3 4 2 4 x`), from the existing shapes; `buildAt` places an added tone on the narrowest grip, then fretted over open, then the easier fingering.

## A shell a player would choose (#1607, #1610)

A shell a player would choose (#1607), four rules. (1) An added tone may not make the grip an open-string one-off (`openOneOff`, in `buildAt`): no open string under fretted notes past the 4th fret (Em7♭5 `x x 2 0 3 6`, E♭m7♭5 `11 0 11 11 x x`), and no more than two open strings at all (Em7♭5 `0 1 0 0 x x`), so no shell on offer is wider than three frets and Em7♭5 at the nut is `x x 2 3 3 3`. One consequence, accepted: with roots kept to the 6th and 5th strings, frets 1–6 hold no complete Em7♭5 and it leaves the window for `x 7 8 7 8 x`. (2) A shell that strums every string — every uke shell, never a guitar one (`strumsEveryString`) — is a strummed chord like the uke triads and takes their costs whole (#1609, `byHand`: `triadUnaryCost`, `triadTransCost`, the first-position open-string credit `openStringCredit`, and `unifyGrips`), so uke C6 is `0 0 0 0` and C7 `0 0 0 1`; a guitar shell is not sent looking for open strings, which there are one-off shapes. (3) A guitar shell is offered ONE barre (`FingerOpts.rootBarre`, `rootBarreOptions`): the index across its lowest fret, only when no finger-per-note fingering gets the root under finger 1 or 2 (G♯°7 `4 x 3 4 3 x` is 2-1-3-1, C6 `x 3 2 2 x x` 2-1-1); the added tone is still placed by finger-per-note effort. (4) A guitar shell whose root NO fingering gets under finger 1 or 2 (`rootBuried`: the R–3–7 shapes of m7♭5 and °7, Dm7♭5 `x 5 3 5 x 4`) is a last resort inside its window (`candidates`): dropped when the window holds another grip, kept when it holds none, so staying in the window still comes first and no chord goes unvoiced. Two more from #1610, both in `candidates`, which takes the first of: grips in the window a player would take; such grips a fret past it with the root in it; any grip in the window; every grip. (5) When the window holds no grip a player would take, it widens by one fret for grips whose ROOT is in it (`inReach`, `REACH`; an open root counts, as an open string does for `inHome`): such a grip belongs to this position rather than another, so it beats a buried root inside (frets 1–6, roots 6/5: E♭m7♭5 `x 6 7 6 7 x`, not `x 6 4 6 x 5`) and beats a grip across the neck when the window holds nothing (E♭maj7 `x 6 5 7 x x`; Emaj7 in frets 2–7 is `0 x 1 1 x x` or `x 7 6 8 x x`, on the costs). It may still be a shift from the chord before, which the costs see. Root outside, or two frets, is left to the costs (Em7♭5 in frets 1–6 is still `x 7 8 7 8 x`); only `classic` roots ever get there, since with the 4th string's shapes every six-fret window holds a grip to take. (6) A three-note guitar shell with an open string is a last resort when the SAME root (string and fret) holds a fully fretted shell (`openShapeOneOff`): the ten R–3–7 grips whose 3rd falls on an open string at the 1st or 2nd fret (B♭7 `x 1 0 1 x x` → `x 1 x 1 3 x`, Fmaj7 `1 0 2 x x x` → `1 x 2 2 x x`). An open ROOT (E7 `0 x 0 1 x x`, Am7 `x 0 x 0 1 x`, Em7 `0 x 0 0 x x`) and a 6 chord at the 1st fret (B♭6 `x 1 x 0 3 x`) have no fretted shell on that root, so this rule leaves them on offer (at the nut those chords are the book's open ones since #1838, and up the neck an open root's skipped string rings, a last resort since #1850); grips with an added tone are `openOneOff`'s.

## Rules gated by kind (#1681)

Because it pins shells, everything newer is gated by `kind`: triad and power grips are offered only to triad/power qualities (`ShapeDef.kind` = `QUALITIES[q].kind`), barres freely only to a non-shell grip and to a ukulele shell, which strums every string as a triad does (#1681; a guitar shell gets just the root barre above), and the `classic` root-string limit applies to shells only. `inversionOf` reads pitch, not string (a re-entrant uke's G string is not its lowest note; the badge is guitar-only).

## Triads costed by the hand; voice-leading on a string set (#1597, #1812)

Triads — and a ukulele's shells — are costed by the fretting hand (fretted notes, open strings earn in first position), never by the root's path; they voice-lead on a string set (#1597: a register term on the grips' lowest strings plus a per-voice step term, a common tone free); on a ukulele the register term is a change of strum, between a grip that sounds the A string and a power grip that leaves it out, and it stays for what it holds: the open A5 beside open chords in frets 2–7, a power riff's one shape, the riffs at the nut (#1812, `triadTransCost`'s comment lists what dropping it moved), while guitar shells keep the root-move cost.

## A ukulele chart stays in first position (#1609, #1809)

A ukulele chart stays in first position (#1609), three rules, all for grips that strum every string (uke shells, uke triads and the four-string uke power grip, C5 `0 0 3 3`; not the three-string one, G5 `0 2 3 x`, and no guitar grip), the first since #1809 for every ukulele grip: a window that starts at fret 1 is first position plus reach, not a middle to aim for, so there the grip is aimed as with no window (`unaryCost`: `defaultTarget` at 0.45 a fret — a blues in G is `0 2 1 2` / `0 0 0 1` / `2 2 2 3`, Am F C G is `2 0 0 0` / `2 0 1 0` / `0 0 0 3` / `0 2 3 2`); an all-open chord at the nut has no hand position (`handFree`: C to Am7 is `0 0 0 3` to `0 0 0 0`, no shift); and a uke shell symbol keeps one grip like a triad's. A window that starts higher keeps its own middle and earns nothing for an open string.

## One grip per symbol (#1599, #1609, #1839)

A triad, power or ukulele-shell symbol written more than once keeps ONE grip (#1599, #1609, `unifyGrips`): after the plan, the chart is re-planned with that symbol (root pitch class + quality) held to each grip it used, and the cheapest is kept unless it costs a position shift (`SAME_GRIP_TOLERANCE`, 2.1) or more per occurrence changed. Guitar shells are left out up the neck and with no window — their comping moves a chord between its two root strings on purpose (with them in, 55 guitar charts of the characterization change) — and held in a window from the 1st fret since #1839, below.

## Ukulele book grips play alone at the nut (#1675)

A ukulele chord that has a BOOK grip plays it, whatever stands beside it (#1675, `bookGrip`, in `candidates`; it began as #1613's preference between the two grips of a split symbol, DECISION 2026-10-12): in first position (no window, or one from fret 1) a strummed chord with a string ringing open and nothing fretted past the 4th fret is offered alone, so the costs choose only between book grips. F between two Cm `0 3 3 3` is `2 0 1 0` (it was `2 5 5 3`, the Em shape as a major, a fret from the Cm on three strings), C beside Fdim or Cdim `0 0 0 3` (`5 4 3 3`), A7 before D7 `0 1 0 0` (`2 4 3 4`), E `1 4 0 2` beside Eaug, Asus2 and G♯m (`1 4 4 2`), a jazz blues in A plays A7 `0 1 0 0` and moves for F♯7 `3 4 2 4`. A tier and not a price, because no price sorts those cases: as a flat credit on the open grip A7 opens beside D7 at 0.4 and F beside Fdim not until 0.8. Every open-string grip the shapes hold inside the 4th fret is one the books print (each was read for #1675); the two that are not, Dsus2 `2 2 0 5` and Fsus2 `0 5 3 3`, reach past it. Up the neck (a window from fret 2 or higher) THIS rule does nothing: an open string there is the hand gone back to the nut, and `Cm F Cm` in frets 2–7 is the closed pair `5 3 3 3` / `5 5 5 3`. Upper windows do change under #1675's other two rules: the five-fret reach below, and the open forms, which are on offer wherever their fretted notes are in the window or a fret past it (A5 `2 4 0 0` in frets 2–7 and 3–8, E5 `4 4 0 2` in frets 2–7).

## Ukulele closed grips in first position (#1688)

A chord with no open grip but a CLOSED one in first position plays that (#1688, `firstPosition`, the step after `bookGrip` in `candidates`): at the nut, a strummed grip with nothing fretted past the 4th fret is offered alone, so a neighbour up the neck no longer pulls the chord after it. Beside Fdim `4 5 4 2`, which has no grip inside the 4th fret, the dim7 is `1 2 1 2`, Bm7♭5 `2 2 1 2`, D♭maj7 `1 1 1 3` and Dm7♭5 `1 2 1 3` (they were `4 5 4 5`, `4 5 5 5`, `5 5 4 4`, `5 5 4 5`); `pop` in F♯ plays C♯7 `1 1 1 2` (was `4 5 4 4`), `canon` in E♭ B♭7 `1 2 1 1` (`3 5 4 5`), B♭m7 beside E♭7 is `1 1 1 1` (`3 5 4 4`), `canon` in B♭ one B♭maj7, `2 2 1 1` (it was split with `3 5 5 5`, past the tolerance), and beside a power chord with no grip there F♯ is `3 1 2 1` (`6 6 6 4` by F♯5 `6 6 9 9`) and B♭ `3 2 1 1` (`3 5 6 5`). D♭sus2 is the book's `1 3 4 4` there, the open Csus2 `0 2 3 3` a fret up: as a sus2 the Cm form may leave its open string while every fret stays inside the 4th (`buildAt`; no other root can), so `D♭ D♭sus2 D♭` is `1 1 1 4` / `1 3 4 4` / `1 1 1 4` (was `6 5 4 4` / `6 3 4 4`) and A♭ beside it `1 3 4 3` (was `5 3 4 3`). Moved further, that form is a stretch no teacher shows (Esus2 `4 6 7 7` for `4 4 2 2`; tried, it changed 80–100 charts per upper window for the worse).

## Ukulele two-string power grips (#1809)

Beside a power chord with no grip near the nut that left the hand jumping to it and back (`F♯ F♯5 F♯` was `3 1 2 1` / `6 6 9 9` / `3 1 2 1`), until the books' two-string power grips came in (#1809, `UKE_TWO_STRING_POWER` in `instruments.ts`, from ukutabs.com: F5 `x 0 1 x`, F♯5/G♭5 `x 1 2 x`, B♭5 `x x 1 1`, B5 `x x 2 2`): two shapes, the 5th on the C string under the root on the E string, and the 5th on the E string beside the root on the A string. They are `nutOnly` (`ShapeDef`): built only inside the 4th fret with a note fretted (`buildAt`; built anywhere, E♭5 `x x 6 6` took `B♭5 F5 E♭5 F5` up the neck), and offered only at the nut (`candidates`; in frets 2–7 `x x 3 3` took `C C5 C` to `5 4 3 3`), and only to a chord with no other grip inside the 4th fret: four strings (C5 `0 0 3 3`, A5, D♭5 `1 1 4 4`) or three (G5 `0 2 3 x`, A♭5 `1 3 4 x`). A muted string costs the plan nothing, so offered beside those they took `G5 Bsus4` to `x 2 3 x` and `E♭5 A♭5` to `… x 3 4 x`, grips no chart gives instead. So F5, F♯5, B♭5 and B5 are the only chords that take them; beside E♭5 `3 3 6 6`, which has no grip near the nut, a riff can still keep B♭5 `3 5 6 x` and F5 `5 5 8 8` as moving shapes, as main did (26 nut charts). So `F♯ F♯5 F♯` is `3 1 2 1` / `x 1 2 x` / `3 1 2 1`, `B B5 B` `4 3 2 2` / `x x 2 2` / `4 3 2 2`, and `D♭5 B5 F♯5 D♭5` `1 1 4 4` / `x x 2 2` / `x 1 2 x` / `1 1 4 4` (D♭5 was pinned mid-riff with B5 and F♯5 up the neck). Power chords stay under `firstPosition`, measured: exempted, 3 charts moved, all D♭5 to `x x 4 4` and one B♭5 beside it to `3 5 6 x`. And every ukulele grip in a window from fret 1 is now aimed as with no window (`unaryCost`, below), so F5 and F♯5 alone in frets 1–6 are `x 0 1 x` / `x 1 2 x` (were `10 12 13 x` / `11 13 14 x`) and B♭5 `x x 1 1` (was `3 5 6 x`). Over 2,982 progressions, uke charts changed: 250 in frets 1–6 (with no window 249; 12 of each are the Dsus4 below), none in a window from fret 2 up; charts with a move of three frets or more in their lowest fretted note went from 152 to 0 in frets 1–6 (150 to 0 with no window). No guitar grip moved, and the shell characterization is unchanged. B5 `x x 2 2` and B♭5 `x x 1 1` are index and middle (1-2), as ukutabs prints them (`UKE_BOOK`, which since #1809 also keys a string left out, `x`); the index barre stays only as fingers left down, beside a chord that bars those strings (B `4 3 2 2` to B5 is 1-1). The finger line says which strings to skip (`skippedStrings` in `app/use-neck-view.ts`) whenever the strings a ukulele grip leaves out change, naming every one the next grip leaves out: B `4 3 2 2` to B5 is "Finger 1 stays down; lift fingers 2 and 3; skip the G and C strings.", B♭5 `x x 1 1` to F5 `x 0 1 x` ends "skip the G and A strings", and a grip back on all four ends "strum all four strings" (F♯5 to F♯); the same strings left out (B5 to B♭5) says nothing, and a guitar never. A chart that opens on such a grip says it first, before Play (`openingSkip`, `neckModel` with no slot: "On B5, skip the G and C strings. …"), since no change leads into it. The board marks those strings too (#1811), below. Known limit: a book grip no shape holds is not played (Eaug is `1 4 4 3`, the book's `1 0 0 3` is the Fm form's layout and not offered).

## A lift to an open string on one root (#1809)

On one root a lift to an open string is not free when it gives up a tone both chords hold (#1809, `holds` in `triadTransCost`, ukulele only): free, Dsus4's grip hung on the chart's order (`D Dsus4 D` gave `2 2 3 0`, `Dsus4 D Dsus4` `0 2 3 0`; `E♭sus4 E♭` `3 3 4 1`, `E♭ E♭sus4` `1 3 4 1`). Now Dsus4 beside D, Dm, D5 or Dsus2 is `2 2 3 0` either way (one finger up a fret, as a teacher slides it), E♭sus4 beside E♭ `0 3 3 1` is `1 3 4 1` (each 3rd up a fret to the 4th), alone they are `0 2 3 0` and `3 3 4 1`, and between roots a lift is still free (C `0 0 0 3` to Am `2 0 0 0`). It moved 12 charts per nut setup, every one a Dsus4.

## Left as they are from #1675's review (#1688)

And three from #1675's review, left as they are on purpose (#1688). (1) A closed grip is never taken at the nut for a chord that has an open book grip: E `4 4 4 2` beside B or Bm, A `2 4 5 4` beside Asus2, E♭ `3 3 3 1` in `E♭ E♭sus4 E♭ E♭sus2` (`0 3 3 1` / `1 3 4 1` / `0 3 3 1` / `3 3 1 1`). Offering it beside the open grip needs a rule that knows the neighbour; left to the costs it undoes #1675 (no price kept E `1 4 0 2` beside Eaug and A7 `0 1 0 0` beside D7). The open grips taken are book grips. (2) The five-fret reach counts frets, not distance. Four frets from the 6th fret up are no wider on the string than frets 1–4, but ranked before the grips a fret outside the window, that reading took Gdim in frets 5–10 from `6 7 6 4` to `6 7 6 10` and Adim in 7–12 from `8 9 8 6` to `8 9 8 12`; a finger per fret a fret out is what a player takes, so A♭m in frets 7–12 is still `8 8 7 6` or `13 11 11 11`, not `8 8 7 11`. (3) Power chords keep the open forms up the neck, and `aFretPast`: E5 `4 4 0 2` in frets 2–7 has its fretted notes there, and in frets 3–8 every A5 but `9 9 12 12` sits a fret below, so `2 4 0 0` is as good as any. Holding the open forms to the nut moved the chords beside them off grips players use (`Am A5 Am` in frets 2–7 to `2 4 5 3` / `2 4 5 x`), and leaving a power chord to the costs once its window holds none took whole charts two frets and more out (`F5 C5 B♭5 C5` in frets 7–12 to `5 5 8 8` / `5 7 8 x` / `3 5 6 x`). So `A5 D5 E5` in frets 5–10 still ends on `4 4 7 7`, not the slide to `9 11 12 x`. One side effect, accepted: at the nut (frets 1–6, or no window), A beside Asus2 was the closed pair `2 4 5 4` / `2 4 5 2` and is now `2 1 0 0` / `2 4 0 2`, both open; in frets 2–7 it is still the closed pair.

## A lone ukulele power chord up the neck (#1814)

A LONE power chord whose window up the neck holds no grip for it (#1814, `powerAFretPast`, a step of its own in `candidates` after `aFretPast`'s) takes the three-string G shape a fret past, where the hand stays, not the four-string grip two frets out that every out-of-window grip tied with on price and that won on the notes it shares with its neighbour: `F F5 F` in frets 7–12 is `10 9 8 8` / `10 12 13 x` / `10 9 8 8` (was `5 5 8 8`), E♭5 beside E♭ in frets 5–10 `8 10 11 x` (was `3 3 6 6`), D♭5 beside D♭ in 3–8 `6 8 9 x` (was `1 1 4 4`). Three limits, each measured: four strings first, so a grip that leaves a string out is taken only where no grip that strums every string is in reach (as the two-string grips at the nut, #1809) and A5 in frets 3–8 stays the book's `2 4 0 0` rather than `2 4 5 x`, which a strummed chart would have to skip the A string for; fretted only, since up the neck an open string is the hand gone back to the nut (offered `0 2 3 x`, `G G5 G` in 3–8 left `7 7 7 5` / `7 7 10 10` for `4 7 7 5` / `0 2 3 x`); and not in a riff (`inRiffAt`: the nearest different chord before or after is a power chord; decided per symbol in `voiceChart`, since `unifyGrips` holds every occurrence of a symbol to one grip and each must be offered the same grips — per occurrence, a lone F5 beside a riff's F5 was left nothing to hold and the voicer threw), where the costs keep the riff's shape (offered there, `A♭5 D♭5 E♭5` in 3–8 went to `8 8 11 11` / `6 8 9 x` / `3 3 6 6`, `C5 F5 G5` in 7–12 to `12 12 15 15` / `10 12 13 x` / `7 7 10 10`). Of 1,801 distinct charts it moved 32, 41 and 34 uke charts in frets 3–8, 5–10 and 7–12, each a lone power chord into reach (a few strummed neighbours re-placed inside the window beside it), none in frets 2–7, at the nut, with no window or on guitar.

## Ukulele first-position forms (#1613, #1675)

Some ukulele chords are first-position FORMS, not shapes (#1613, #1675, `UKE_OPEN_FORMS`, and two in `UKE_POWER`): Fm `1 0 1 3`, E `1 4 0 2` and Cm `0 3 3 3`, then Esus4 `2 4 0 2` (the E form, its 3rd up a fret), Csus2 `0 2 3 3` (the Cm form, its 3rd down one), Asus2 `2 4 0 2` (a form of its own: Esus4's four frets and three notes with A as the root), A5 `2 4 0 0` and E5 `4 4 0 2`. Each is offered for the qualities it is taught for (`ShapeDef.qualities`, read by `allowedShapes` and by `build`) and only where its string rings open (`ShapeDef.openOnly`, in `buildAt`), which is one root — free to move or change quality the same layouts beat the book's F `2 0 1 0`, F♯m `2 1 2 0` and Em `0 4 3 2`. The sus2 shape on the Fm layout does move (Fsus2 `0 0 1 3`, F♯sus2 `1 1 2 4`), and the Cm form as a sus2 moves inside the 4th fret only (D♭sus2 `1 3 4 4`, #1688). Before them Fm was `1 5 4 3`, Esus4 and Asus2 `4 4 5 2`, Csus2 `5 2 3 3`, A5 `2 4 5 x`, and E5 `4 4 7 7` — or the 9th fret in frets 1–6, which hold no `4 4 7 7`. Not added: A♭ `5 3 4 3` is already on offer and `1 3 4 3` (the G shape barred) wins on cost; the 7th grips D7 `2 0 2 0`, F7 `2 3 1 0`, Fmaj7 `5 5 0 0` and B♭maj7 `3 2 1 0` (the grips produced are book grips, and D7 `2 0 2 0` has no root, which the four shell shapes are built from).

## Ukulele five-fret reaches (#1675)

A ukulele grip FIVE FRETS WIDE is a last resort (#1675, `fiveFretReach`, in `candidates` beside the guitar shell's buried root): the minor, dim and sus2 forms of the Em shape, whose G-string note drops four frets below the rest (Gm `3 7 6 5`, B♭m `6 10 9 8`, Fdim `1 5 4 2`) where the D shape plays the same chord in three (`7 7 6 5`, `10 10 9 8`, `4 5 4 2`), and of the C shape, which reaches up for its top note (Ddim `1 2 1 5`, E♭m `3 3 2 6`). Both are grips only on their open strings (Em `0 4 3 2`, C♯m `1 1 0 4`; the span is read off fretted notes), and the major forms are fine (F♯ `3 6 6 4`). Up the neck, where a window holds nothing else, it widens by a fret before one is taken (`aFretPast`, #1610's `REACH`, with no root rule: a ukulele chord's root moves with its shape): E♭m in frets 2–7 is `3 3 2 1` or `8 6 6 6`, F♯m in frets 5–10 `6 6 5 4` or `11 9 9 9`. So in a window from fret 2 up a ukulele triad may sit one fret outside, and up to frets 9–14 none sits two out or is five frets wide (Bdim in frets 10–15 still is, where the neck ends). In FIRST POSITION a reach beats leaving (`leavesTheNut`): it gives way only to a grip that stays inside frets 1–6 (`NUT_WINDOW`, the nut window's own top and not the 4th fret a book grip is held to, since Fdim `4 5 4 2` has a 5th-fret note), and a window from the nut never widens. Known limit: Ddim is `1 2 1 5` at the nut, the one triad with no other grip there, wide and kept on purpose. At `7 5 4 5` it took the chart with it (`B♭ Ddim E♭ F` opened on B♭ `3 5 6 5`, `F7 Ddim` on `5 5 5 6`) or hopped five frets and back for one chord. With no window at all it can still follow a neighbour that is itself up the neck (`F5 Ddim`: `5 5 8 8` / `7 5 4 5`), as it did before. A dim triad stays a triad: the dim7 `1 2 1 2` a teacher plays for Ddim adds a note the symbol does not name.

## Fingers planned across the chart; shells' taught fingerings (#1611)

Fingers are planned across the chart (`fingerSequence`) so a note two chords share keeps its finger, and only between fingerings a grip is taught with (`taughtOptions` in `fingering.ts`). A SHELL's are `taughtAmong` (#1611). Four rules: no dearer than the cheapest fingering by more than `TAUGHT_MARGIN` (1: which fingers take the notes is a choice, at most 0.8; a fret of stretch is not, at least 2.8 — G7 `3 x 3 4 x x` is 1-2-3 or 2-3-4, never 1-2-4); root first where the cheapest fingering is, whatever the price (D7 `x 5 4 5 x x` is 2-1-3 after Am7♭5, never 3-2-4; G°7 `3 x 2 3 2 x` is the barre 2-1-3-1, though a finger per note is only 1 dearer there); no idle index over a stretch (C7 `x 3 x 3 5 x` is never 2-3-4); and nobody ARRIVES with the index behind the nut — the lowest finger on a fret below its own number — so E7 `0 x 0 1 x x` takes the index and Fmaj7 `1 x 2 2 x x` 1-2-3 cold, but a finger already down is not lifted (`needs: 'left'`, `arrives`, `sharesTheHand`): F7 `1 x 1 2 x x` to B♭maj7 `x 1 x 2 3 x` keeps the ring finger and plays 2-3-4 exactly as G7 to Cmaj7 does two frets up, and uke G7 `0 2 1 2` to Cmaj7 `0 0 0 2` leaves it down. Left in place means no finger is swapped for another on a string both chords fret. One fingering the rules would drop comes back with a reason: the minor 7th in position (`inPosition`: Dm7 `x 5 3 5 x x` as 3-1-4, 6th- and 5th-string R–♭3–♭7, and the three-note 4th-string °7), taken only to keep the hand on a neighbour in its own cheapest fingering — in practice a triad (Dm7 into B♭ `x 5 3 3 x x`); with nothing to keep it is 2-1-3, and Dm7 to G7 never keeps "finger 2" (that was 3-2-4). A marked fingering must hold a finger of its own (`FingerOption.own`): a note the cheapest fingering keeps as well is no reason. The rules live in the plan, NOT in `handCost` or `fingerOptions`, because grip choice reads those (`buildAt`'s added-tone effort, `rootBuried`): #1611 moved no grip.

## Triad and power fingerings held to what is taught (#1617)

Triad and power grips are held to what is taught too (#1617, `taughtStrummed`), and the chart is planned in ONE pass (the pass that froze a triad's fingers beside a shell is gone). Three rules, the first two the shell's: no dearer than the cheapest by more than `TAUGHT_MARGIN` and no idle index over a stretch (B♭ `x 5 3 3 x x` is the barre 3-1-1, never 4-2-3; uke B `4 3 2 2` is 3-2-1-1); no ring or little finger laid flat closer to the index than a finger apiece would sit (`crampedBarre`: F `x 3 3 2 x x` is 2-3-1, not 3-3-1; two frets up it is the A shape's ring barre); and where the cheapest lays the ring or little finger flat, the fingertip-per-note fingering in position is taught beside it, priced at the margin so one held note can choose it (power chord 1-3-3 or 1-3-4, A shape 3-3-1 or 3-4-1; uke E♭m `3 3 2 1` has both too, the fingertips first since #1677). The nut rule holds for them as for shells (uke A `2 1 0 0` is 2-1, F `2 0 1 0` 2-1; the others only as fingers left down).

## The ukulele fingering table (UKE_BOOK)

A short TABLE overrules the costs for the ukulele chords whose method-book fingering the rules do not reach (`UKE_BOOK`, `UKE_F_SHAPE`, keyed by the four strings' frets and looked up for a ukulele grip only): Fm `1 0 1 3` 1-2-4, E♭ `0 3 3 1` 2-3-1 (or the barre, or 3-4-1: the books disagree, all three stay), Cm `0 3 3 3` the barre or 1-2-3 (#1677), and the F shape fretted on all four strings (F♯ `3 1 2 1`, G `4 2 3 2`, A♭ `5 3 4 3`) as the index barre 3-1-2-1 at every fret. ## A change of fingering costs only re-fingered shared notes (#1617)

## Ukulele fingering rules (#1681)

Every UKULELE chord, 7th or triad, is fingered as the ukulele is taught (#1681, `FingerOpts.ukulele`, set by `fingerRules` from the instrument; fingers only, no fret moved, and no guitar fingering changed). Three rules. (1) A ukulele shell is a strummed chord and goes through `taughtStrummed` with barres, not `taughtAmong`: the finger-per-note rule exists so a guitar shell's fretting hand can mute the strings it skips, and a ukulele shell skips none — D7 `2 2 2 3` is 1-1-1-2, Bm7 `2 2 2 2` one finger, B♭7 `1 2 1 1` 1-2-1-1, A♭maj7 `1 3 3 3` 1-3-3-3, B♭maj7 `2 2 1 1` 2-3-1-1, Gm7 `0 2 1 1` 0-2-1-1, and no ukulele grip shows four fingertips on one fret. (2) No barre lies on an open string (`barreOptions`; a guitar's strummed grips too since #1677): a flat finger reaches its strings from the palm side, so an open string of the grip numbered below the run is under it. D `2 2 2 0` is 1-2-3 (2-3-4 beside a chord that keeps two of those fingers), Asus4/Dsus2 `2 2 0 0` 1-2, C♯m `1 1 0 4` 1-2-4, Faug `2 1 1 0` 3-1-2, Dsus4 `2 2 3 0` 1-2-3 (from D two fingers stay and the ring finger moves up a fret); an open string beyond the fingertip is clear (Gm7 `0 2 1 1`, Gmaj7 `0 2 2 2` and Cm `0 3 3 3` are barres). This one is in `fingerOptions`, because the fingertip fingering it leaves is more than 4 dearer than the barre and was never on offer; no ukulele grip is chosen by fingering cost, so it moves no grip. (3) A ukulele chord leaves its default fingering only for TWO fingers that stay (`FingerOption.hold`, `heldFingers`, checked in `arrives`), or its one finger when it uses one (and since #1677 for one finger when one is all it moves, `holdFor`): a second fingering is offered as `needs: 'before'`/`'after'` and fingers left down as `'left'`, each with the count. One held finger dragged the hand a fret behind its place (`Am Dm E7`: E7 `1 2 0 2` was 2-3-0-4, now 1-2-0-3; `Cm Fm G7`: G7 `0 2 1 2` was 0-3-2-4, now 0-2-1-3); two still choose (Dm7♭5 `1 2 1 3` to G7 0-3-2-4, G to Em 0-4-3-2, Bm7♭5 to E7 2-3-0-4), one-finger chords keep their finger (Cmaj7 `0 0 0 2` after G7, C after Fm), and the table's printed alternatives take one (E♭ `0 3 3 1`). A guitar grip still takes a second taught fingering for one held note, except one that takes an open grip's hand off the nut (#1683, below). Also: the margin is measured from the cheapest fingering that is not a cramped barre, so A♭m7♭5 `1 2 2 2` stays 1-2-3-4 rather than 1-2-3-3 (on three strings the cheapest is never cramped, so no guitar grip is affected).

## The leftovers of #1617 and #1681 (#1677)

The leftovers of #1617 and #1681, as a guitar teacher and a ukulele teacher settled them (#1677; fingers only, no fret moved on either instrument). GUITAR, three rules. Open C `x 3 2 0 x x` is 3-2, G `x 2 0 0 x x` the middle finger, and those are what choose 2-3 over 1-2 in (1). The fingerings it passes over stay as SECOND fingerings (`needs: 'before'`/`'after'`): C as 2-1 into Am `x 3 2 2 x x` kept both fingers until #1835 made C never 2-1 and that Am 3-2-1 (below), Em as 1-2 into C the middle finger, and A as 1-2 into D the index until #1834 made that 1-3 (below). Shells are left alone: A7 `x 0 x 0 2 x` is still the index, because the same rule there would finger Dmaj7 `x x 0 x 2 2` as 2-3. (3) A shell's default is the in-position fingering where its cheapest is out of position and the in-position one is within the margin (`taughtAmong`): one shape, the maj7 on strings 4, 2 and 1, Fmaj7 `x x 3 x 5 5`, 1-3-4 cold where it was 1-2-3. That was true only of what a fingering may sit beside; what it COSTS was still charged every bar, so an unmarked second fingering lost to the default once its chord lasted long enough. Since #1683 a fingering's own cost is paid once for a run of one chord (`sameFingers`, in `planFingers`), and a chart fingers the same whatever the bar count (below). UKULELE. `FingerOpts.ukulele` is read off the instrument, so the three-string power chord (G5 `0 2 3 x`) gets the ukulele's rules too. Known limits. ## Barres derived; the neck is presentational (#1594, #1592, #1811)

A barre (#1594) is DERIVED from notes sharing a finger (`barres`, `fingerMap`'s lead note), never stored. Colour means degree, always; fingers get numbers and motion, never colour. The neck is presentational — voicing in, SVG out; no runtime, state or document imports; it marks each string the grip leaves silent with a × (#1811, `.neck-mute`, `data-mute` = string number), drawn where an open string's dot sits beside the nut, in ink, in every label mode (a chart prints × and o whatever it writes in the dots), dimmed with the grip under a hold or N.C., never pulsed by the strike and never drawn for the preview's next grip (the finger line names a change of strings); zoomed up the neck, with the nut out of view, it sits in the first fret in view (`viewWindow` keeps that fret clear of both grips' notes), in the strings' colour on the wood, beside the grip as a chart prints it; and the board's label ends with the strings (`; 6th, 2nd and 1st strings not played`, `; G and C strings not played`); its preview shows where the next grip is, not how to get there, unless `fingers` is on (#1592).
